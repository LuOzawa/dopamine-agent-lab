# AI Agent 学习站

以 [runoob · AI Agent 教程](https://www.runoob.com/ai-agent/ai-agent-tutorial.html) 为蓝本的本地学习站：8 阶段、47 节，多巴胺风格。

## 打开

双击 `index.html`。纯静态、无外部字体/CDN、无需服务器；进度保存在本机 `localStorage`。

## 内容

- `index.html` 学习地图、总进度、优先更新
- `stage-1.html` ～ `stage-8.html` 47 节，每节含目标 / 前置 / 要点 / 动手 / 自检
- `contents.html` 对照原文 3 组 48 项的全部目录
- `frameworks.html` 13 个框架 + 8 个工具的选型矩阵
- `search.html` 全文搜索
- `audit.html` 47 行内容审计 + 12 条更新对照
- `about.html` 假设声明、设计令牌、维护与待核实清单
- `examples/` 第 5、6 阶段可运行实验与下载包
- `tools/` 章节、索引与示例构建脚本
