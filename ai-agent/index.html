Learning Path

8 个阶段，从概念到能跑起来

阶段之间是递进关系，但不必严格按顺序：有 Python 基础可以直接从阶段 5 开始，做产品的可以从阶段 6 切入。

如何新增一节
1

认知地图

先搞清楚 Agent 到底是什么、由哪些部件组成、术语在说什么。不写代码，但决定后面学得顺不顺。

4 节 · 约 1.5h入门
2

模型与提示

LLM 如何生成、多模态能做什么、提示词为什么有效、Token 如何计费——Agent 的能力边界都在这里。

5 节 · 约 2h基础
3

推理、知识与上下文

CoT / ReAct / 规划、向量检索与 RAG、上下文预算。解决「模型不知道」和「想不清楚」两类问题。

4 节 · 约 2h核心
4

架构与工具选型

六种 Agent 架构、平台/框架/库的差别、工作流与自主 Agent 的边界。先选对形态，再谈实现。

3 节 · 约 1.5h决策
5

亲手构建

不依赖框架，用 Python 写出 Agent 循环、工具调用、记忆与最小 RAG。这一阶段决定你是「会用」还是「会造」。

7 节 · 约 4.5h实战
6

框架与平台

LangChain 1.x、LangGraph、CrewAI、Deep Agents、Dify、n8n、GraphRAG。学会在正确场景选正确的工具。

7 节 · 约 4h工具
7

前沿产品与工程范式

Vibe Coding、Harness / Loop Engineering，以及 OpenClaw、Pi、Hermes 等终端与桌面 Agent。看清趋势，也看清权限风险。

9 节 · 约 3h趋势
8

多智能体、生产化与扩展

多 Agent 协作、MCP / Computer Use、评估与安全、生产部署，以及微调与 3D 这类扩展场景。

8 节 · 约 4h进阶
