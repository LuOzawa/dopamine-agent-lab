使用说明

这一页写清四件事：本站基于什么假设做的、怎么打开与维护、设计令牌怎么改、哪些内容必须你自己核实。

01打开方式

站点是纯静态文件，不需要安装、不需要服务器、不需要联网：

  1. 把整个 ai-agent-learning/ 文件夹放在本机任意位置（不要只拷贝单个 HTML）。
  2. 双击 index.html，默认浏览器会以 file:// 协议打开。
  3. 进度存在浏览器的 localStorage：换浏览器、清理站点数据或使用无痕模式都会丢失。
  4. 首页会根据上次阅读的小节和完成记录提供「继续学习」入口；完成上次小节后，会推荐后续未完成的小节。
  5. 少数浏览器在 file:// 或严格隐私模式下会禁用 localStorage：保存失败时页面会显示持续提示。当前更改仅临时有效，修复存储设置或空间问题后可点「重试保存」。
  6. 手机和平板可展开阅读区顶部的「本阶段目录」跳转小节；跳转后目录自动收起。

如果样式丢失：通常是把 HTML 单独移动了位置。页面引用的是 assets/style.css 相对路径，必须和 assets/ 目录保持同级。

字体与尺寸

  • 字体：系统中文字体栈（PingFang SC / 微软雅黑 / Noto Sans SC），不加载外部字体，避免离线失败与中文 webfont 体积。
  • 正文 16px / 行高 1.75；标题使用 clamp() 响应式缩放；代码使用等宽字体栈。
  • 间距按 4px 节奏：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64；卡片圆角 16–24px。
  • 阴影使用「实色偏移」而非模糊阴影（3px 3px 0），与粗描边形成贴纸感，同时不牺牲文字对比。

组件规范

动效规范

  • 只动 transform 与 opacity；时长 150–220ms；缓动 cubic-bezier(.2,.8,.2,1)。
  • 悬停位移不超过 3px；不做自动轮播、闪烁、无限循环动画。
  • prefers-reduced-motion: reduce 时关闭所有位移与过渡，滚动改回即时。
  • 进度条与圆环只随「标记完成」变化，属于状态反馈而非装饰。

04如何新增或修改一节

  1. 在对应 stage-N.html 中复制一个 <article class="lesson"> 整块。
  2. 改三处：id="sN-M"、lesson-badge 的编号、data-done-id="sN-M"；三处必须一致。
  3. 补全五个字段：学习目标、前置知识、核心要点、动手任务、自检（每个至少 1 条）。
  4. 在左侧目录 .toc 里加一条锚点；如果是原文已有章节，在 contents.html 对应分组里加一行并指向新锚点；本站扩展则标注「本站扩展」。
  5. 运行 python3 tools/link_chapters.py：重建全站章级前后篇，并自动同步 STAGE_TOTAL。
  6. 运行 python3 tools/build_search_index.py：把新增/修改的要点纳入全文搜索。
  7. 刷新页面，点一次「标记完成」，确认进度条与圆环同步变化。

只改配色：编辑 style.css 的 :root 变量即可，全站生效。 若某个阶段要换主色，改对应页面的 body[data-accent] 与 .stage-card 的 --sc。 改完请重新核对前景/背景对比度，正文不低于 4.5:1。
