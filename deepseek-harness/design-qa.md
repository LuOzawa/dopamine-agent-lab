# 第 3 方案 · 设计验收

final result: passed

参考：`design/reference.png`，1487 × 1058。实现同尺寸、deviceScaleFactor 1，独立浏览器记录为 8/33、继续阅读 2.5。未修改用户的浏览器进度。

## 第一轮发现

- P2 · 目录行距：目录行约 93px，参考约 69px，导致路线区下移约 140px。收紧编号行高和目录标题下间距。
- P2 · 字体：衬线方向一致，但标题、目录与品牌字重及品牌字级偏轻偏小。增加展示字重，微调标题和品牌字号。
- P2 · 主操作：继续阅读按钮偏窄，进度与按钮距离不足。调整按钮宽度、字号以及操作区间隔。

首轮证据：`design/qa/comparison-initial.png`。

## 修复与复核

- 目录编号、箭头和元信息采用独立行高，行高回到约 69px；路线区恢复到参考首屏对应位置。
- 增强标题、目录、品牌字重，增加品牌分隔线与字号；再次检查时发现加粗导致首页标题第三行，随后收紧流动字号，桌面恢复两行。
- 主按钮改为墨色、约 440px 宽，进度独立排在其右侧；移动端允许自然换行与自适应宽度。
- 原有继续阅读说明转为按钮的可访问描述；动态进度、完整小节 aria-label、首次阅读及全部完成状态仍保留。
- 扩大验收时修复目录筛选的既有问题：显式隐藏带 hidden 属性的 grid 行。

最终并排证据：`design/qa/comparison.png`。局部证据：`design/qa/comparison-opening.png`、`design/qa/comparison-routes.png`。截图同画布、同缩放、同进度状态；未从分开的图片推断对齐。

## 功能与适配验收

- 继续阅读：首次阅读、上次未完成、已完成后的推荐、全部完成、无效记录。
- 进度：标记、撤销、完成、刷新、存储失败提示、恢复保存。
- 导航：六章入口、四条路线键盘展开与跳转、移动目录、滚动定位和焦点。
- 内容：目录筛选有结果/无结果/清空恢复；搜索、多关键词高亮、结果总数、清空参数。
- 示例：复制成功、复制拒绝与手动选择、旧式复制回退；无 JS 时隐藏复制按钮并保留示例文本。
- 离线：直接打开文件时的目录与搜索；不增加 CDN 或字体请求。
- 320、390、768、1024、1440 五档宽度通过；六种页面类型另保存桌面与移动截图。
- 11 个 HTML、475 处本地引用、唯一 ID 检查通过；隔离构建完整复现 13 个生成产物。
